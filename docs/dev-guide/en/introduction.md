# cjr Developer Guide

cjr is implemented in Rust. A single Cargo package provides the CLI and library. The user interface is limited to program execution, `inspect`, `list` and `cache clean`.

Update both language editions of the user guide when command behavior changes. Prefer the standard library and maintained dependencies for general infrastructure. Version metadata, official asset selection, cjv compatibility and cache policy belong to cjr.

The repository contains source code, ordinary tests and maintained documentation. Keep research directories, downloaded SDKs, probes, audit or acceptance reports and generated output in ignored local directories.

Report problems and suggestions through [GitHub Issues](https://github.com/Zxilly/cjr/issues). Read recent commit messages before committing and follow the existing style.
