cjr_

仓颉程序，直接运行。

读取程序中的 SDK 版本，自动准备对应的官方运行库。已有 cjv 缓存时优先复用。

$cjr ./app

Windows x64 · Linux x64 · macOS ARM64 / x64

从源码安装

需要 Rust 1.89+、C 编译器和 CMake。

cargo install --git https://github.com/Zxilly/cjr --locked
查看安装说明 →

带上程序路径即可

程序路径之后的参数原样传给应用。

cjr ./app --port 8080

缓存准备好后，使用 cjr --offline ./app 离线运行。Windows 路径可写为 .\app.exe。

版本与缓存，随时查看

cjr inspect ./app
查看版本和依赖
cjr list
列出本地缓存
cjr cache clean --dry-run
预览清理内容
